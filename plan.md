## Required features

### Create posts

- [ ] Provide a form to create a post.
- [ ] Require a post title.
- [ ] Allow optional additional text content.
- [ ] Allow an optional image through an external image URL.

### Home feed

- [ ] Display previously created posts.
- [ ] By default, show only each post's creation time, title, and upvote count.
- [ ] Keep body text and images on the individual post page, not the default feed.
- [ ] Open a separate page for the selected post when clicked.

### Sort and search

- [ ] Allow sorting posts by creation time.
- [ ] Allow sorting posts by upvote count.
- [ ] Allow searching posts by title.

### Post page and interactions

- [ ] Show the selected post's additional content, image, and comments on its own page.
- [ ] Allow users to leave comments underneath the post.
- [ ] Include an upvote button that increases the count by one per click.
- [ ] Allow users to upvote any post any number of times.
- [ ] Allow a previously created post to be edited from its post page.
- [ ] Allow a previously created post to be deleted from its post page.

## Stretch features (optional)

### Pseudo-authentication

- [ ] Implement one of the following pseudo-authentication options:
  - [ ] Require a user-set secret key to edit/delete posts or delete comments.
  - [ ] Assign a random user ID on launch, associate it with the user's posts and comments, and display it on them.
- [ ] Restrict post updates and deletion to the original author for either option.

### Reposts and threads

- [ ] Allow reposting a previous post by referencing its post ID.
- [ ] Display and link the referenced post on the new post's page to create a thread.

### Interface customization

- [ ] Allow users to customize the interface (for example, choose a color scheme or opt into displaying post content and images in the home feed).

### Additional post characteristics

- [ ] Allow users to share and view web videos.
- [ ] Allow users to set flags such as "Question" or "Opinion" when creating a post.
- [ ] Allow filtering the home feed by flags.
- [ ] Allow uploading image files directly from the user's local machine.

### Loading state

- [ ] Display a loading animation whenever data is being fetched.
